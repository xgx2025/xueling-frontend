# xueling-frontend
“学灵”智能学习网站的前端

## 局域网访问

在本机运行 `npm run dev`，然后让同一局域网中的设备访问 Vite 输出的 Network 地址。当前配置会监听所有网络接口；例如本机 Wi-Fi 地址为 `192.168.1.23`、端口为 `5173` 时，访问 `http://192.168.1.23:5173/`。IP 和端口可能变化，以启动输出为准。

如果本机能打开而其他设备超时，检查 Windows 防火墙是否允许 Node.js 在当前网络上接收入站连接，并确认路由器没有启用客户端隔离。前端通过 Vite 的 `/api` 代理访问本机 `9012` 端口的后端，因此前后端需在同一台电脑上运行，页面中的接口功能才能正常使用。

单词记忆功能集中在 `src/features/vocab/`：页面位于 `views/`，接口、类型、复习状态和词族组件由该功能目录维护。其他页面仍在 `src/view/`。
